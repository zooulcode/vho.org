The "Active" system is a web-based application developed for the Volunteer Hub Organization (VHO) to manage volunteer attendance effectively. It supports role-based access for Admins, HR personnel, Committee Headers, and Volunteers, with multilingual support (Arabic and English). The system allows secure login and account creation, location-based check-ins for physical meetings, and online attendance tracking. A core function of the system is to calculate and store volunteer working hours based on their attendance, enabling the organization to monitor individual contributions for reporting, evaluation, and recognition purposes. The platform also provides reminders before meetings and visual analytics for attendance data. In future phases, the system will be extended to include task assignment and tracking features# vho.org
